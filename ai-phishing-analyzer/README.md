# 🎣 AI Phishing Email Analyzer

> One-machine project: Python app + detection logic + optional local AI explanation
>
> `Python` · `Streamlit` · `Ollama (optional)` · Portfolio-ready

A Streamlit app that scores a pasted email (or uploaded `.eml` file) for
phishing indicators using rule-based heuristics, with an optional plain-language
explanation generated by a **locally running** LLM via [Ollama](https://ollama.com)
— no data ever leaves your machine, no API keys required.

## Features

- Paste raw email text or upload a `.eml` file
- Detects common phishing signals:
  - urgency / pressure language
  - requests for credentials or financial data
  - generic greetings ("Dear Customer")
  - IP-address links instead of domains
  - URL shorteners
  - suspicious top-level domains
  - sender display-name vs. domain mismatch (e.g. "PayPal Support" from a random domain)
  - excessive punctuation / ALL CAPS
  - link text that doesn't match its actual destination
- Weighted 0–100 risk score with a Low / Medium / High / Critical rating
- Optional natural-language explanation from a local Ollama model
- Two sample emails included (`sample_emails/`) — one phishing, one legitimate

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

Then open the local URL Streamlit prints (usually http://localhost:8501).

Try it with the included samples: upload `sample_emails/phishing_paypal.eml`
or `sample_emails/legit_newsletter.eml` and click **Analyze**.

## Optional: local AI explanation

The heuristic score works out of the box with zero setup. To also get a
plain-language explanation from a local model:

1. Install [Ollama](https://ollama.com)
2. Pull a small model: `ollama pull llama3.2`
3. In the app, toggle **"Add AI explanation (local Ollama)"**

If Ollama isn't running, the app just skips this step with a friendly
message — the heuristic analysis still works fully.

## How scoring works

Each matched signal in `detector.py` adds a weight to a 0–100 score:

| Signal | Weight |
|---|---|
| Sender / display name mismatch | 25 |
| Sensitive data request | 20 |
| IP-address link | 20 |
| Link text / destination mismatch | 20 |
| Urgency language | 15 |
| URL shortener | 12 |
| Suspicious TLD | 10 |
| Generic greeting | 8 |
| Excessive punctuation / caps | 5 |

`0–19` Low · `20–44` Medium · `45–69` High · `70+` Critical
